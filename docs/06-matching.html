8  Matching

Le document illustre l’application de la méthode de matching dans l’analyse. L’objectif de cette méthode est d’équilibrer les échantillons, c’est-à-dire de maximiser la comparabilité entre les groupes de traitement et de contrôle en termes de caractéristiques observables (ho2007?). Nous comparons donc des groupes traités et contrôles en les appariant selon 5 covariables environnementales (taux de couvert forestier en 2000, la pente, l’altitude, la densité de population en 2000 et l’accessibilité en 2000).

En effet, si les deux groupes sont très différents avant le traitement, il est difficile de savoir si les différences observées après viennent du traitement ou simplement de ces différences initiales. D’où l’importance du matching, qui permet de neutraliser ces différences. Plus précisement, nous utilisons le genetic matching, une variante des méthodes de matching. Bien qu’ayant le même objectif, cette approche repose sur des algorithmes d’optimisation qui ajustent les facteurs de confusion susceptibles d’influencer à la fois la probabilité de recevoir le traitement et les résultats observés.

8.1 Méthodes

Nous réalisons le matching à l’aide de la méthode genetic matching du package R MatchIt, en appelant directement matchit(method = "genetic", distance = "mahalanobis", ...). Cette méthode combine les variables de matching en une seule mesure unique de distance “Mahalanobis distance matching”. Cette distance mesurera la différence entre les unités des groupes appariés pour quantifier la similitude entre les deux groupes d’observations, tout en tenant compte des corrélations entre les covariables et de leurs covariances (Diamond and Sekhon 2013). L’algorithme génétique (via Matching::GenMatch, appelé en interne par matchit()) sélectionne les facteurs d’échelle attribués à chaque covariable afin de maximiser l’équilibre entre le groupe de traitement et le groupe de contrôle, puis les paires sont formées en une seule étape.

prep_matching <- function(df_final) {
  out <- df_final %>%
    filter(GROUP %in% c("Treatment","Control")) %>%
    mutate(treatment = if_else(GROUP == "Treatment", 1L, 0L))
  
  missing_cols <- setdiff(matching_variables, names(out))
  if (length(missing_cols) > 0) {
    message(">> Colonnes manquantes: ", paste(missing_cols, collapse=", "))
  }
  
  out %>% drop_na(all_of(intersect(matching_variables, names(out))))
}

# réutilisés que si le hash de spécification est identique.
FORCE_REMATCH <- FALSE

# Arguments du matching (source unique du hash de spécification)

# Hash de spécification : tout changement d'assignation du traitement, des
# covariables, des arguments du matching ou de la graine invalide le cache.
matching_spec_hash <- function(year, dat_m, X_match, seed) {
  digest::digest(list(
    spec_version = "review_v2",
    year = year,
    treatment = dat_m$treatment,
    row_ids = paste(dat_m$DHSYEAR, dat_m$hv001, dat_m$hv002, sep = "-"),
    matching_variables = matching_variables,
    X = X_match,
    matching_arguments = matching_arguments,
    seed = seed
  ), algo = "sha256")
}

# SMD absolu par covariable (définition standard, écarts-types bruts)
smd_by_var <- function(df, vars) {
  X <- as.matrix(df[vars])
  tr <- df$treatment == 1
  m_t <- colMeans(X[tr, , drop = FALSE])
  m_c <- colMeans(X[!tr, , drop = FALSE])
  v_t <- apply(X[tr, , drop = FALSE], 2, var)
  v_c <- apply(X[!tr, , drop = FALSE], 2, var)
  abs((m_t - m_c) / sqrt((v_t + v_c) / 2))
}

run_matching_year <- function(year, force = FORCE_REMATCH) {
  cat("\n=== Matching", year, "===\n")
  fin_path <- glue("data/derived/hr_{year}_final.rds")
  if (!file.exists(fin_path)) stop("Fichier introuvable: ", fin_path)

  dat   <- readRDS(fin_path)
  dat_m <- prep_matching(dat)

  n_total <- nrow(dat)
  n_filt <- nrow(dat_m)
  n_treat <- sum(dat_m$treatment == 1, na.rm = TRUE)
  n_ctrl <- sum(dat_m$treatment == 0, na.rm = TRUE)

  cat(glue(">> N total={n_total}, après filtre/NA={n_filt}; ",
           "Traités={n_treat}, ",
           "Contrôles={n_ctrl}\n"))

  have_all_vars <- all(matching_variables %in% names(dat_m))
  cat(">> Toutes les covars présentes ? ", have_all_vars, "\n")
  if (n_filt < 5 || !have_all_vars) {
    warning(glue("Année {year}: données insuffisantes ou variables manquantes — on saute."))
    return(NULL)
  }

  # Garde-fou : GROUP valide partout où il est renseigné, et aucune
  # observation Treatment issue d'une AP "Proposed" (aucune reclassification
  # issue d'un RDS périmé). Les ménages des clusters retirés pour coordonnées
  # GPS invalides (9 en 2008, 1 en 2011) ont GROUP manquant : ils ne peuvent
  # pas être classés et sont exclus du matching (comme auparavant).
  prop_ids <- readr::read_csv(
    "data/PA_creation/wdpa_data/dynamic_wdpa_metadata.csv",
    show_col_types = FALSE) |>
    dplyr::filter(STATUS == "Proposed") |>
    dplyr::pull(WDPAID)
  stopifnot(
    "GROUP invalide dans les données de matching" =
      all(dat$GROUP[!is.na(dat$GROUP)] %in% c("Treatment", "Control", "Excluded")),
    "GROUP manquant parmi les observations éligibles au matching" =
      all(!is.na(dat_m$GROUP)),
    "treated_now incohérent" =
      all(dat_m$treated_now[dat_m$treatment == 1L] %in% c(0L, 1L)),
    "Treatment rattaché à une AP Proposed" =
      !any(dat_m$WDPAID[dat_m$treatment == 1L] %in% prop_ids)
  )

  X_match <- dat_m %>%
    sf::st_drop_geometry() %>%
    dplyr::select(all_of(matching_variables)) %>%
    as.data.frame()

  seed <- MATCHING_BASE_SEED + as.integer(year)
  spec_hash <- matching_spec_hash(year, dat_m, X_match, seed)

  match_path       <- glue("data/derived/matching_result_{year}.rds")
  matched_out_path <- glue("data/derived/data_matched_{year}.rds")

  # --- matchit(method = "genetic") en une seule étape ---
  used_cache <- FALSE
  t0 <- Sys.time()
  if (!force && file.exists(match_path)) {
    cached <- tryCatch(readRDS(match_path), error = function(e) NULL)
    if (!is.null(cached) && !is.null(cached$meta) &&
        identical(cached$meta$spec_hash, spec_hash)) {
      cat(">> matchit: cache valide (hash identique) -> lecture\n")
      m_out <- cached$m_out
      used_cache <- TRUE
    } else {
      cat(">> matchit: cache absent ou périmé (hash différent) -> recalcul\n")
    }
  }
  if (!used_cache) {
    cat(glue(">> matchit: calcul en cours (seed = {seed}, hash = {substr(spec_hash, 1, 12)})...\n"))
    set.seed(seed)
    fml <- as.formula(paste("treatment ~", paste(matching_variables, collapse=" + ")))

    # TODO(caliper) : le caliper préenregistré de 0.25 SD sera réexaminé dans
    # une revue séparée ; il n'est PAS appliqué ici.
    m_out <- matchit(
      formula   = fml,
      data      = dat_m,
      method    = "genetic",
      distance  = "mahalanobis",
      estimand  = "ATT",
      replace   = FALSE,
      ratio     = 1,
      pop.size  = 1000,
      max.generations = 100,
      wait.generations = 4
    )

    saveRDS(list(
      m_out = m_out,
      meta = list(
        spec_version = "review_v2",
        spec_hash = spec_hash,
        seed = seed,
        year = year,
        matching_variables = matching_variables,
        matching_arguments = matching_arguments,
        n_eligible = n_filt,
        n_treated = n_treat,
        n_control = n_ctrl
      )
    ), match_path)
  }
  t_match <- as.numeric(difftime(Sys.time(), t0, units="mins"))
  cat(glue(">> matchit temps = {round(t_match,1)} min (cache={used_cache})\n"))

  matched <- match.data(m_out, data = sf::st_drop_geometry(dat_m)) %>%
    dplyr::filter(weights > 0)

  # Chaque observation appariée porte un GROUP valide
  stopifnot(
    "GROUP invalide dans l'échantillon apparié" =
      all(matched$GROUP %in% c("Treatment", "Control"))
  )

  saveRDS(matched, matched_out_path)
  cat(glue(">> N appariés = {nrow(matched)} (écrit: {matched_out_path})\n"))

  tibble(
    Année = year,
    'Total des observations' = n_total,
    'Après filtre/NA' = n_filt,
    Traités = n_treat,
    Contrôles = n_ctrl,
    'N appariés' = nrow(matched),
    'Traités appariés' = sum(matched$treatment == 1L),
    'Contrôles appariés' = sum(matched$treatment == 0L),
    'Part écartés' = 1 - nrow(matched) / n_filt,
    'SMD max avant' = max(smd_by_var(dat_m, matching_variables)),
    'SMD max après' = max(smd_by_var(matched, matching_variables)),
    seed = seed,
    hash = substr(spec_hash, 1, 12)
  )
}

# Harmonisation du diagnostic d'équilibre : cobalt est le diagnostic
# standard du workflow de matching / du PAP. Sous estimand ATT, cobalt
# standardise l'écart de moyennes par l'écart-type du groupe traité, tandis
# que smd_by_var() ci-dessus utilise l'écart-type pooled des deux groupes ;
# les deux définitions coexistent dans le tableau, la lecture de référence
# pour le critère SMD <= 0.1 est celle de cobalt.
cobalt_smd <- map_dfr(seq_along(yrs), function(i) {
  bt <- bal_tabs[[i]]
  if (is.null(bt)) {
    return(tibble(Year = yrs[i],
                  SMD_before_cobalt = NA_real_,
                  SMD_after_cobalt = NA_real_))
  }
  bal <- as.data.frame(bt$Balance)
  adj_col <- grep("^Diff\\.Adj$", colnames(bal), value = TRUE)[1]
  # SMD avant appariement : bal.tab(matchit) ne calcule Diff.Un que si
  # un = TRUE ; on le recalcule explicitement sur les données brutes.
  dat_raw <- readRDS(glue("data/derived/hr_{yrs[i]}_final.rds")) %>%
    filter(GROUP %in% c("Treatment", "Control")) %>%
    mutate(treatment = if_else(GROUP == "Treatment", 1L, 0L)) %>%
    # même échantillon éligible que le matching (exclusion des NA de covariables)
    tidyr::drop_na(all_of(matching_variables))
  bal_pre <- cobalt::bal.tab(
    reformulate(matching_variables, response = "treatment"),
    data = as.data.frame(sf::st_drop_geometry(dat_raw)),
    estimand = "ATT", un = TRUE, abs = TRUE
  )$Balance
  tibble(
    Year = yrs[i],
    SMD_before_cobalt = max(abs(bal_pre$Diff.Un), na.rm = TRUE),
    SMD_after_cobalt = if (!is.na(adj_col))
      max(abs(bal[[adj_col]]), na.rm = TRUE) else NA_real_
  )
})

result_list <- result_list %>%
  left_join(cobalt_smd, by = "Year") %>%

derived_dir  <- "data/derived"

# --- Pre-compute Raw_HH_all from raw source files ---

# DHS/MIS: read only first column of each HR .DTA (fast row count)

                           recursive = TRUE, full.names = TRUE, ignore.case = TRUE)
dhs_hr_paths <- dhs_hr_paths[!grepl("SPSS|wealth", dhs_hr_paths, ignore.case = TRUE)]

  tryCatch(nrow(read_dta(f, col_select = 1L)), error = function(e) NA_integer_)
}) |>
  set_names(str_extract(dhs_hr_paths, "DHS_(\\d{4})", group = 1))

mics_all <- tryCatch(
  nrow(read_sav(mics_hh_file, col_select = 1L)),
  error = function(e) NA_integer_
)

# --- Build table row by row ---

out <- map_dfr(years, function(y) {
  y_chr         <- as.character(y)
  hr_file       <- file.path(derived_dir, paste0("hr_", y_chr, "_final.rds"))
  matched_file  <- file.path(derived_dir, paste0("data_matched_", y_chr, ".rds"))
  matchres_file <- file.path(derived_dir, paste0("matching_result_", y_chr, ".rds"))

  # Raw HH (all): from raw source files
  Raw_HH_all <- if (y == 2018) mics_all else as.integer(dhs_all_map[y_chr])

  # Defaults
  Raw_HH_rural      <- NA_integer_
  Excluded_group    <- NA_integer_
  Treatment_Control <- NA_integer_
  After_NA_drop     <- NA_integer_
  Treated           <- NA_integer_
  Matched_rows      <- NA_integer_

  # hr_final: rural-only file with GROUP assigned and matching covariates
  if (file.exists(hr_file)) {
    hr           <- readRDS(hr_file)
    Raw_HH_rural <- nrow(hr)
    if ("GROUP" %in% names(hr)) {
      Excluded_group    <- sum(hr$GROUP == "Excluded", na.rm = TRUE)
      Treatment_Control <- sum(hr$GROUP %in% c("Treatment", "Control"), na.rm = TRUE)
      Treated           <- sum(hr$GROUP == "Treatment", na.rm = TRUE)
    }
  }

  # matching_result: matchit object (revue v2 : liste m_out + meta) —
  # X matrix rows = inputs to matching (after NA drop)
  if (file.exists(matchres_file)) {
    mr <- readRDS(matchres_file)
    mobj <- if (is.list(mr) && !is.null(mr$m_out)) mr$m_out else mr
    if (is.list(mobj) && "X" %in% names(mobj)) {
      After_NA_drop <- nrow(mobj$X)
      if (is.na(Treated) && "treat" %in% names(mobj)) {
        Treated <- sum(mobj$treat == 1L)
      }
    }
  }

  # Matched rows: actual row count from matched dataset (not 2 × Treated)
  if (file.exists(matched_file)) {
    Matched_rows <- nrow(readRDS(matched_file))
  }

  tibble(
    Year              = y,
    Survey            = survey_map[y_chr],
    Raw_HH_all        = Raw_HH_all,
    Raw_HH_rural      = Raw_HH_rural,
    Excluded_group    = Excluded_group,
    Treatment_Control = Treatment_Control,
    After_NA_drop     = After_NA_drop,
    Treated           = Treated,
    Matched_rows      = Matched_rows
  )
})

8.4 Checking covariate balance

Les modèles d’appariement reposent sur l’hypothèse que les distributions des covariables sont similaires entre les groupes de traitement et de contrôle, rendant cruciale l’évaluation de l’équilibre des covariables. La validité des estimations dépend directement de la qualité de cet équilibre, d’où l’importance de réaliser des tests pour le mesurer. On effectue donc un test d’équilibre des covariables en deux étapes: un test avant appariement et un test après appariement.

8.4.0.1 Balance test before matching

Pour effectuer le test avant l’appariement, on détermine les déséquilibres initiaux à partir du test de Standardized Mean Difference (SMD). Le SMD mesure l’écart entre les moyennes des covariables dans les groupes de traitement et les groupes de contrôle pour comparer l’équilibre relatif des variables mesurées dans des unités différentes:

  • Si |SMD| < 0.1, il existe un équilibre satisfaisant entre les groupes pour la covariable.

  • Si SMD > 0.1, le déséquilibre est significatif (austin2009?). Pour réajuster l’équilibre, on augmentera l’intervalle des calipers afin d’obtenir un SMD ≤ 0.1.

# Equilibre des covariables
check_balance_before <- function(df, year, matching_variables) {
  
  data <- df %>%
    filter(GROUP %in% c("Treatment", "Control")) %>%
    mutate(treatment = if_else(GROUP == "Treatment", 1, 0))

  formula <- reformulate(matching_variables, response = "treatment")
  
  # Balance avant appariement
  bal_before <- bal.tab(
    formula,
    data = data,
    estimand = "ATT",
    un = TRUE,
    abs = TRUE
  )
  
  # Extraction du Standardized Mean Difference (SMD)
 balance_df <- bal_before$Balance %>%
    as.data.frame() %>%
    tibble::rownames_to_column("Variable")

  smd_col <- grep("Diff|Std", names(balance_df), value = TRUE)[1]

  smd_table <- balance_df %>%
    dplyr::select(Variable, SMD = all_of(smd_col)) %>%
    mutate(
      Year = year,
      Equilibre = if_else(abs(SMD) <= 0.1, "Balanced", "Unbalanced")
    ) %>%
    relocate(Year)

  return(smd_table)
}

8.4.0.2 Balance test after matching: Quantile- quantile QQ Plot analysis

Le test après appariement sera un test visuel de la qualité du matching en comparant la distribution de chaque covariable à partir d’un plot. La méthode graphique offre une vue d’ensemble de la distribution des covariables. Le graphique facilite ainsi l’identification des déséquilibres à différents niveaux de la distribution. Lorsque les points Q-Q plot se situent près de la diagonale, le quantile des deux distributions sont similaires, signalant ainsi un bon équilibre. Si les points s’écartent de la diagonale, cela indique que la distribution de l’échantillon diffère de la distribution théorique.
