8  Matching

Le document illustre l’application de la méthode de matching dans l’analyse. L’objectif de cette méthode est d’équilibrer les échantillons, c’est-à-dire de maximiser la comparabilité entre les groupes de traitement et de contrôle en termes de caractéristiques observables (Ho et al. 2007). Nous comparons donc des groupes traités et contrôles en les appariant selon 5 covariables environnementales (taux de couvert forestier en 2000, la pente, l’altitude, la densité de population en 2000 et l’accessibilité en 2000).

En effet, si les deux groupes sont très différents avant le traitement, il est difficile de savoir si les différences observées après viennent du traitement ou simplement de ces différences initiales. D’où l’importance du matching, qui permet de neutraliser ces différences.

8.1 Méthodes

Plan préenregistré (PAP). Le PAP prévoit un Genetic Matching / appariement au plus proche voisin sur distance de Mahalanobis (Diamond and Sekhon 2013), une logique de caliper (rosenbaum_central_1983?), un critère d’équilibre SMD ≤ 0.10, l’élargissement du caliper en cas de dépassement de ce seuil, la possibilité d’exclure les observations non appariées, et la combinaison des poids de matching avec les poids d’enquête DHS. Le PAP ne spécifie ni ratio fixe 1:1 ni règle de remplacement.

Problème observé (avant tout examen des outcomes). L’implémentation directe de ce plan s’est révélée problématique en pratique : le Genetic Matching sans caliper satisfaisait le critère SMD ≤ 0.10 (définition cobalt, estimand ATT) dans six vagues mais échouait en 2013 (déséquilibre persistant de population_count_2000), tandis que l’implémentation d’un caliper marginal de 0.25 écart-type sur chaque covariable provoquait une attrition sévère des ménages traités et un mauvais équilibre dans plusieurs vagues (diagnostic scripts/diag_matching_caliper.R).

Déviation outcome-blind retenue. Le design de production retient désormais le profile matching cardinality sous estimand ATT : matchit(method = "cardinality", estimand = "ATT", ratio = NA, tols = 0.095, std.tols = TRUE, solver = "highs"). Ce design sélectionne le plus grand sous-ensemble apparié équilibré avec tous les ménages traités fixes comme cible : il retient 100 % des traités, maximise l’échantillon de contrôles utilisable et impose directement le critère SMD ≤ 0.10 preregistre, avec exactement les cinq covariables de matching du PAP et la même population éligible. Le choix a été fait avant l’inspection de tout outcome sous ce design. Le tols = 0.095 n’est qu’une garde numérique garantissant une marge par rapport à la borne : le critère substantiel reste l’équilibre externe max |SMD| ≤ 0.10 (définition cobalt). Le profile cardinality matching est une déviation méthodologique documentée, pas un estimateur préenregistré (voir documentation/matching_design_freeze.md, commit b89b8c2) ; il n’était pas préenregistré dans le PAP, et le PAP n’exigeait pas de ratio 1:1. Le cardinality 1:1 et l’entropy balancing ATT sont réservés à des robustesses ultérieures.

prep_matching <- function(df_final) {
  out <- df_final %>%
    filter(GROUP %in% c("Treatment","Control")) %>%
    mutate(treatment = if_else(GROUP == "Treatment", 1L, 0L))
  
  missing_cols <- setdiff(matching_variables, names(out))
  if (length(missing_cols) > 0) {
    message(">> Colonnes manquantes: ", paste(missing_cols, collapse=", "))
  }
  
  out %>% drop_na(all_of(intersect(matching_variables, names(out))))
}

# supprimer toute ancienne version pour éviter le masquage
if (exists("run_matching_year")) rm(run_matching_year)

# Revue v2 : graine de base fixe, graine spécifique par vague (reproductibilité)
MATCHING_BASE_SEED <- 20261004L

# Revue v2 : la première exécution doit forcer une relance complète de toutes
# les vagues (les anciens caches, sans métadonnées de spécification, sont de
# toute façon invalidés par l'échec de validation du hash). Une fois ce
# rematch initial effectué, passer à FALSE : les caches ne sont alors
# réutilisés que si le hash de spécification est identique.
FORCE_REMATCH <- FALSE

# Regle figee avant toute inspection d'outcome
# (documentation/matching_design_freeze.md, commit b89b8c2) :
# profile matching cardinality ATT. FINAL_PROFILE_TOL = 0.095 n'est qu'une
# garde numerique ; le critere substantiel reste max |SMD| externe <= 0.10.
FINAL_PROFILE_TOL <- 0.095

# Arguments du matching (source unique du hash de specification)
matching_arguments <- list(
  method = "cardinality",
  estimand = "ATT",
  ratio = NA,
  tols = FINAL_PROFILE_TOL,
  std.tols = TRUE,
  solver = "highs"
)

# Versions de paquets (entrent dans le hash de specification)
pkg_versions <- list(
  R = paste(R.version$major, R.version$minor, sep = "."),
  MatchIt = as.character(packageVersion("MatchIt")),
  cobalt = as.character(packageVersion("cobalt")),
  highs = as.character(packageVersion("highs"))
)

# Hash de specification : tout changement d'assignation du traitement, des
# covariables, des arguments du matching, des versions de paquets ou de la
# graine invalide le cache. spec_version passe a "review_v2_profile" :
# les anciens caches genetic matching sont de fait invalides.
matching_spec_hash <- function(year, dat_m, X_match, seed) {
  digest::digest(list(
    spec_version = "review_v2_profile",
    year = year,
    treatment = dat_m$treatment,
    row_ids = paste(dat_m$DHSYEAR, dat_m$hv001, dat_m$hv002, sep = "-"),
    matching_variables = matching_variables,
    X = X_match,
    matching_arguments = matching_arguments,
    package_versions = pkg_versions,
    seed = seed
  ), algo = "sha256")
}

# SMD absolu par covariable (définition standard, écarts-types bruts)
smd_by_var <- function(df, vars) {
  X <- as.matrix(df[vars])
  tr <- df$treatment == 1
  m_t <- colMeans(X[tr, , drop = FALSE])
  m_c <- colMeans(X[!tr, , drop = FALSE])
  v_t <- apply(X[tr, , drop = FALSE], 2, var)
  v_c <- apply(X[!tr, , drop = FALSE], 2, var)
  abs((m_t - m_c) / sqrt((v_t + v_c) / 2))
}

run_matching_year <- function(year, force = FORCE_REMATCH) {
  cat("\n=== Matching", year, "===\n")
  fin_path <- glue("data/derived/hr_{year}_final.rds")
  if (!file.exists(fin_path)) stop("Fichier introuvable: ", fin_path)

  dat   <- readRDS(fin_path)
  dat_m <- prep_matching(dat)

  n_total <- nrow(dat)
  n_filt <- nrow(dat_m)
  n_treat <- sum(dat_m$treatment == 1, na.rm = TRUE)
  n_ctrl <- sum(dat_m$treatment == 0, na.rm = TRUE)

  cat(glue(">> N total={n_total}, après filtre/NA={n_filt}; ",
           "Traités={n_treat}, ",
           "Contrôles={n_ctrl}\n"))

  have_all_vars <- all(matching_variables %in% names(dat_m))
  cat(">> Toutes les covars présentes ? ", have_all_vars, "\n")
  if (n_filt < 5 || !have_all_vars) {
    warning(glue("Année {year}: données insuffisantes ou variables manquantes — on saute."))
    return(NULL)
  }

  # Garde-fou : GROUP valide partout où il est renseigné, et aucune
  # observation Treatment issue d'une AP "Proposed" (aucune reclassification
  # issue d'un RDS périmé). Les ménages des clusters retirés pour coordonnées
  # GPS invalides (9 en 2008, 1 en 2011) ont GROUP manquant : ils ne peuvent
  # pas être classés et sont exclus du matching (comme auparavant).
  prop_ids <- readr::read_csv(
    "data/PA_creation/wdpa_data/dynamic_wdpa_metadata.csv",
    show_col_types = FALSE) |>
    dplyr::filter(STATUS == "Proposed") |>
    dplyr::pull(WDPAID)
  stopifnot(
    "GROUP invalide dans les données de matching" =
      all(dat$GROUP[!is.na(dat$GROUP)] %in% c("Treatment", "Control", "Excluded")),
    "GROUP manquant parmi les observations éligibles au matching" =
      all(!is.na(dat_m$GROUP)),
    "treated_now incohérent" =
      all(dat_m$treated_now[dat_m$treatment == 1L] %in% c(0L, 1L)),
    "Treatment rattaché à une AP Proposed" =
      !any(dat_m$WDPAID[dat_m$treatment == 1L] %in% prop_ids)
  )

  X_match <- dat_m %>%
    sf::st_drop_geometry() %>%
    dplyr::select(all_of(matching_variables)) %>%
    as.data.frame()

  seed <- MATCHING_BASE_SEED + as.integer(year)
  spec_hash <- matching_spec_hash(year, dat_m, X_match, seed)

  match_path       <- glue("data/derived/matching_result_{year}.rds")
  matched_out_path <- glue("data/derived/data_matched_{year}.rds")

  # --- matchit(method = "cardinality") : regle figee ---
  # Profile matching ATT : le plus grand sous-ensemble equilibre avec tous
  # les traites fixes comme cible. Pas d'etape d'appariement par paires
  # Mahalanobis apres selection : le profile matching est un design de
  # selection d'ensemble equilibre, pas un appariement par paires.
  # Solveur deterministe : pas de set.seed necessaire au calcul.
  used_cache <- FALSE
  t0 <- Sys.time()
  if (!force && file.exists(match_path)) {
    cached <- tryCatch(readRDS(match_path), error = function(e) NULL)
    if (!is.null(cached) && !is.null(cached$meta) &&
        identical(cached$meta$spec_hash, spec_hash)) {
      cat(">> matchit: cache valide (hash identique) -> lecture\n")
      m_out <- cached$m_out
      used_cache <- TRUE
    } else {
      cat(">> matchit: cache absent ou perime (hash different) -> recalcul\n")
    }
  }
  if (!used_cache) {
    cat(glue(">> matchit: calcul en cours (hash = {substr(spec_hash, 1, 12)})...\n"))
    fml <- as.formula(paste("treatment ~", paste(matching_variables, collapse=" + ")))

    m_out <- matchit(
      formula   = fml,
      data      = dat_m,
      method    = "cardinality",
      estimand  = "ATT",
      ratio     = NA,
      tols      = FINAL_PROFILE_TOL,
      std.tols  = TRUE,
      solver    = "highs",
      time      = 1800
    )

    saveRDS(list(
      m_out = m_out,
      meta = list(
        spec_version = "review_v2_profile",
        spec_hash = spec_hash,
        seed = seed,
        year = year,
        matching_variables = matching_variables,
        matching_arguments = matching_arguments,
        package_versions = pkg_versions,
        n_eligible = n_filt,
        n_treated = n_treat,
        n_control = n_ctrl
      )
    ), match_path)
  }
  t_match <- as.numeric(difftime(Sys.time(), t0, units="mins"))
  cat(glue(">> matchit temps = {round(t_match,2)} min (cache={used_cache})\n"))

  matched <- match.data(m_out, data = sf::st_drop_geometry(dat_m)) %>%
    dplyr::filter(weights > 0)

  # Chaque observation appariée porte un GROUP valide
  stopifnot(
    "GROUP invalide dans l'échantillon apparié" =
      all(matched$GROUP %in% c("Treatment", "Control"))
  )

  # Gardes de production de la regle figee : retention 100% des traites,
  # toutes les PA traitees representees, equilibre externe cobalt <= 0.10,
  # poids de design verifies. Profile matching : poids de design 1 pour les
  # unites retenues (traites et controles), 0 pour les controles ecartes.
  n_t_elig <- sum(dat_m$treatment == 1L)
  n_t_match <- sum(matched$treatment == 1L)
  bt_year <- cobalt::bal.tab(m_out, estimand = "ATT", un = TRUE)
  smd_year <- abs(bt_year$Balance$Diff.Adj)
  w_t <- matched$weights[matched$treatment == 1L]
  w_c <- matched$weights[matched$treatment == 0L]
  stopifnot(
    "retention des traites < 100%" = n_t_match == n_t_elig,
    "PA traitee non representee dans l'echantillon apparié" =
      setequal(unique(dat_m$WDPAID[dat_m$treatment == 1L]),
               unique(matched$WDPAID[matched$treatment == 1L])),
    "equilibre externe cobalt > 0.10" = max(smd_year) <= 0.10 + 1e-8,
    "poids de design traites != 1" = all(abs(w_t - 1) < 1e-8),
    "poids de design controles retenus != 1" = all(abs(w_c - 1) < 1e-8)
  )
  cat(glue(">> gardes design : traites {n_t_match}/{n_t_elig} (100%), ",
           "max SMD cobalt = {round(max(smd_year), 4)}, ",
           "poids design = 1 (traites et controles retenus)\n"))

  saveRDS(matched, matched_out_path)
  cat(glue(">> N appariés = {nrow(matched)} (écrit: {matched_out_path})\n"))

  tibble(
    Année = year,
    'Total des observations' = n_total,
    'Après filtre/NA' = n_filt,
    Traités = n_treat,
    Contrôles = n_ctrl,
    'N appariés' = nrow(matched),
    'Traités appariés' = sum(matched$treatment == 1L),
    'Contrôles appariés' = sum(matched$treatment == 0L),
    'Part écartés' = 1 - nrow(matched) / n_filt,
    'SMD max avant' = max(smd_by_var(dat_m, matching_variables)),
    'SMD max après' = max(smd_by_var(matched, matching_variables)),
    seed = seed,
    hash = substr(spec_hash, 1, 12)
  )
}

# Harmonisation du diagnostic d'équilibre : cobalt est le diagnostic
# standard du workflow de matching / du PAP. Sous estimand ATT, cobalt
# standardise l'écart de moyennes par l'écart-type du groupe traité, tandis
# que smd_by_var() ci-dessus utilise l'écart-type pooled des deux groupes ;
# les deux définitions coexistent dans le tableau, la lecture de référence
# pour le critère SMD <= 0.1 est celle de cobalt.
cobalt_smd <- map_dfr(seq_along(yrs), function(i) {
  bt <- bal_tabs[[i]]
  if (is.null(bt)) {
    return(tibble(Year = yrs[i],
                  SMD_before_cobalt = NA_real_,
                  SMD_after_cobalt = NA_real_))
  }
  bal <- as.data.frame(bt$Balance)
  adj_col <- grep("^Diff\\.Adj$", colnames(bal), value = TRUE)[1]
  # SMD avant appariement : bal.tab(matchit) ne calcule Diff.Un que si
  # un = TRUE ; on le recalcule explicitement sur les données brutes.
  dat_raw <- readRDS(glue("data/derived/hr_{yrs[i]}_final.rds")) %>%
    filter(GROUP %in% c("Treatment", "Control")) %>%
    mutate(treatment = if_else(GROUP == "Treatment", 1L, 0L)) %>%
    # même échantillon éligible que le matching (exclusion des NA de covariables)
    tidyr::drop_na(all_of(matching_variables))
  bal_pre <- cobalt::bal.tab(
    reformulate(matching_variables, response = "treatment"),
    data = as.data.frame(sf::st_drop_geometry(dat_raw)),
    estimand = "ATT", un = TRUE, abs = TRUE
  )$Balance
  tibble(
    Year = yrs[i],
    SMD_before_cobalt = max(abs(bal_pre$Diff.Un), na.rm = TRUE),
    SMD_after_cobalt = if (!is.na(adj_col))
      max(abs(bal[[adj_col]]), na.rm = TRUE) else NA_real_
  )
})

8.4 Checking covariate balance

Les modèles d’appariement reposent sur l’hypothèse que les distributions des covariables sont similaires entre les groupes de traitement et de contrôle, rendant cruciale l’évaluation de l’équilibre des covariables. La validité des estimations dépend directement de la qualité de cet équilibre, d’où l’importance de réaliser des tests pour le mesurer. On effectue donc un test d’équilibre des covariables en deux étapes: un test avant appariement et un test après appariement.

8.4.0.1 Balance test before matching

Pour effectuer le test avant l’appariement, on détermine les déséquilibres initiaux à partir du test de Standardized Mean Difference (SMD). Le SMD mesure l’écart entre les moyennes des covariables dans les groupes de traitement et les groupes de contrôle pour comparer l’équilibre relatif des variables mesurées dans des unités différentes:

  • Si |SMD| < 0.1, il existe un équilibre satisfaisant entre les groupes pour la covariable.

  • Si SMD > 0.1, le déséquilibre est significatif (Austin 2009). Le PAP prévoyait d’élargir l’intervalle des calipers pour rétablir l’équilibre ; sous le design figé (profile cardinality ATT, voir documentation/matching_design_freeze.md), le critère SMD ≤ 0.1 est imposé directement comme contrainte d’optimisation, ce qui rend l’élargissement itératif du caliper sans objet.

# Equilibre des covariables
check_balance_before <- function(df, year, matching_variables) {
  
  data <- df %>%
    filter(GROUP %in% c("Treatment", "Control")) %>%
    mutate(treatment = if_else(GROUP == "Treatment", 1, 0))

  formula <- reformulate(matching_variables, response = "treatment")
  
  # Balance avant appariement
  bal_before <- bal.tab(
    formula,
    data = data,
    estimand = "ATT",
    un = TRUE,
    abs = TRUE
  )
  
  # Extraction du Standardized Mean Difference (SMD)
 balance_df <- bal_before$Balance %>%
    as.data.frame() %>%
    tibble::rownames_to_column("Variable")

  smd_col <- grep("Diff|Std", names(balance_df), value = TRUE)[1]

  smd_table <- balance_df %>%
    dplyr::select(Variable, SMD = all_of(smd_col)) %>%
    mutate(
      Year = year,
      Equilibre = if_else(abs(SMD) <= 0.1, "Balanced", "Unbalanced")
    ) %>%
    relocate(Year)

  return(smd_table)
}

8.4.0.2 Balance test after matching: Quantile- quantile QQ Plot analysis

Le test après appariement sera un test visuel de la qualité du matching en comparant la distribution de chaque covariable à partir d’un plot. La méthode graphique offre une vue d’ensemble de la distribution des covariables. Le graphique facilite ainsi l’identification des déséquilibres à différents niveaux de la distribution. # Pour tous les années confondues
make_balance_table <- function(data, year, csv_path = NULL, folder = "data/derived") {
  df_year <- data %>% filter(Year == year)
  
  tab <- df_year %>%
    gt() %>%
    tab_header(
      title = "Covariates balance after matching",
      subtitle = paste("Year", year)
    ) %>%
    cols_label(
      Year = "Year",
      Variable = "Variable",
      SMD_before = "SMD before",
      SMD_after  = "SMD after"
    ) %>%
    fmt_number(
      columns = c(SMD_before, SMD_after),
      decimals = 3
    )
  
  if (!is.null(csv_path)) {
    write.csv(df_year, csv_path, row.names = FALSE)
  }
  
  return(tab)
}
