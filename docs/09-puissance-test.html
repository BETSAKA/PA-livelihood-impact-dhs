11  Puissance statistique

Ce document recalcule la puissance statistique de l’étude en s’alignant strictement sur les choix d’analyse effectués dans 06-matching.qmd et 07-estimation_staggered.qmd :

  • Échantillon : ménages ruraux appariés (fichiers data_matched_{year}.rds produits par le genetic matching), groupes Treatment et Control uniquement.
  • Résultat principal : wealth_centile_rural_weighted (indice de richesse pondéré, comme dans l’estimation H1), avec une section dédiée à H2 (zscore_wealth, résultat d’inégalité).
  • Poids : poids d’enquête × poids de matching (w_all), comme dans l’estimation.
  • Clustering : ICC estimée au niveau du cluster (hv001), conformément au clustering des erreurs standards.
  • Design : MDE pour (i) le 2×2 DiD (2008–2021) et (ii) le design échelonné sur toutes les vagues ; plus une MDE empirique calculée directement à partir de l’erreur standard du coefficient de traitement du modèle réel.

Par rapport à la version antérieure, ce document apporte trois améliorations :

  1. les quantiles de t utilisés pour la MDE empirique sont fondés sur le nombre de clusters (df = G − 1), et non sur les degrés de liberté résiduels, conformément à l’inférence cluster-robuste ;
  2. l’approche par design effect — celle utilisée à la phase de pré-enregistrement — incorpore la correction CV₁ pour les tailles de grappes inégales, et le calcul effectué dans le PAP est reproduit puis expliqué ;
  3. la MDE par design effect est comparée à la MDE empirique, qui fait référence : l’écart entre les deux est décomposé et les raisons de la sous-estimation à la phase de pré-enregistrement sont documentées.

11.5 MDE estimée à la phase de pré-enregistrement (approche par design effect)

Le plan d’analyse préalable (pre-analysis_plan/PAP.qmd) a estimé la MDE à la phase de pré-enregistrement avec l’approche par design effect : \(DE = 1 + (m-1)\rho\), avec \(m\) la taille moyenne des grappes. Lorsque les tailles de grappes sont inégales, la correction CV₁ de Kerry & Bland (2001) remplace \(m\) par \(m\,(1 + CV^2)\), où \(CV\) est le coefficient de variation des tailles de grappes : \[DE_{CV_1} = 1 + \big((1 + CV^2)\, m - 1\big)\rho.\]

Pour le 2×2, la variance commune est estimée sur les ménages de l’échantillon apparié, avec pondération. Pour le design échelonné, les vagues pré-traitement renforcent la puissance ; la borne reste indicative.

Code 
pooled_sd <- sqrt(
  Hmisc::wtd.var(dat[[yvar]], dat$w_all, na.rm = TRUE)
)

# MDE avec design effect corrigé CV1
mde_analytic <- function(df, sample_label) {
  g <- df %>%
    group_by(treat) %>%
    summarise(n_hh = n(), n_clust = n_distinct(cluster_uid), .groups = "drop")

  # CV des tailles de grappes, calculé par groupe
  cv_by_group <- df %>%
    count(treat, cluster_uid) %>%
    group_by(treat) %>%
    summarise(cv = sd(n) / mean(n), .groups = "drop")
  g <- g %>%
    left_join(cv_by_group, by = "treat") %>%
    mutate(m = n_hh / n_clust) %>%
    transmute(
      treat,
      n_hh, n_clust, m, cv,
      de_naive    = 1 + (m - 1) * icc_value,
      de_cv1      = 1 + ((1 + cv^2) * m - 1) * icc_value,
      n_eff_naive = n_hh / de_naive,
      n_eff_cv1   = n_hh / de_cv1
    )
  res_naive <- pwr.t2n.test(n1 = g$n_eff_naive[2], n2 = g$n_eff_naive[1],
                            sig.level = alpha, power = power)
  res_cv1   <- pwr.t2n.test(n1 = g$n_eff_cv1[2],   n2 = g$n_eff_cv1[1],
                            sig.level = alpha, power = power)
  tibble(
    Sample         = sample_label,
    m_treated      = g$m[2],
    m_control      = g$m[1],
    cv_treated     = g$cv[2],
    cv_control     = g$cv[1],
    de_naive       = g$de_naive[2],
    de_cv1         = g$de_cv1[2],
    cohens_d_naive = res_naive$d,
    cohens_d_cv1   = res_cv1$d,
    mde_units      = res_cv1$d * pooled_sd
  )
}

res_2x2_analytic  <- mde_analytic(filter(dat, DHSYEAR %in% c(2008, 2021)),
                                  "2x2 DiD (2008-2021)")
res_stag_analytic <- mde_analytic(dat, "Échelonné (toutes vagues)")

11.5.1 Reproduction du calcul effectué à la phase de pré-enregistrement

Le PAP rapportait : ICC = 0,4783 ; écart-type = 28,87 ; d = 0,258 ; MDE = 7,45 points de centile. Ce calcul reposait sur les ménages traités seuls, non appariés, de la vague 2021, avec un groupe contrôle supposé identique au groupe traité. On le reproduit ici sur les données actuelles :

Code 
# Méthode du PAP : ménages traités non appariés, vague 2021 uniquement,

treatment_clusters_2021 <- read.csv("data/derived/cluster_treatment_classification_staggered.csv") %>%

  pull(DHSCLUST)

  filter(hv001 %in% treatment_clusters_2021)

icc_pre_fit <- lmer(wealth_centile_rural_simple ~ 1 + (1 | hv001),
                    data = hh_2021, REML = TRUE)
vc_pre <- as.data.frame(VarCorr(icc_pre_fit))
var_between_pre <- vc_pre$vcov[vc_pre$grp == "hv001"]
var_within_pre  <- vc_pre$vcov[vc_pre$grp == "Residual"]

11.5.2 Pourquoi la MDE a été sous-estimée à la phase de pré-enregistrement

L’écart entre la MDE de la phase de pré-enregistrement (7,5–9,6 points de centile selon la version des données) et la MDE empirique observée (16,0 points pour le 2×2, 11,9 points pour le design échelonné) provient de quatre sources, par ordre d’importance :

  1. La formule du design effect ne modélise pas la variance réelle du coefficient DiD. Elle approxime la MDE par une comparaison simple de moyennes post-traitement entre deux groupes à grappes égales. Or l’erreur standard réelle de treat_post intègre la variance d’une interaction (la décomposition de la SE ci-dessous montre que le passage de la comparaison simple à la spécification complète multiplie la SE par ~1,6), les contrôles, et l’effet des poids d’enquête × matching (~×1,1).
  2. Tailles de grappes inégales et déséquilibre entre bras. La formule suppose des grappes de taille égale et une répartition symétrique ; en réalité les grappes traitées sont plus peuplées que les grappes contrôles (m ≈ 31 contre 24), et la correction CV₁ n’était pas appliquée.
  3. Groupe contrôle supposé identique au groupe traité. Le PAP n’avait pas encore réalisé le matching et supposait que le contrôle aurait même taille et même variabilité que le traitement ; cette hypothèse ne tient pas dans l’échantillon apparié réel.
  4. Corrections des dates de création des AP. La correction des dates de création a retiré du périmètre des AP créées après 2008, réduisant l’échantillon de traitement (de 15 328 à 13 444 ménages appariés ; de 566 à 481 clusters) et donc la puissance par rapport aux calculs intermédiaires.

11.6 MDE empirique à partir du modèle réel (2×2)

La MDE la plus fidèle à l’analyse est dérivée directement de l’erreur standard du coefficient treat_post du 2×2 DiD estimé dans 07-estimation_staggered.qmd (mêmes données, poids et clustering) : \(MDE = (t_{1-\alpha/2,\,df} + t_{power,\,df}) \times SE\), avec \(df = G - 1\) où \(G\) est le nombre de clusters, conformément à l’inférence cluster-robuste.

Code 
post2 <- dat %>% filter(DHSYEAR %in% c(2008, 2021))

main2 <- post2 %>%
  mutate(post = as.integer(DHSYEAR == 2021),
         treat_post = treat * post)

f_main <- reformulate(
  c("treat", "post", "treat_post",
    "spei_wc_n_2", "spei_wc_n_1", "spei_wc_n", "hv219", "hv220"),
  response = yvar
)

m_main <- feols(f_main, data = main2, weights = ~ w_all, cluster = ~ cluster_uid)

se <- broom::tidy(summary(m_main)) %>%
  filter(term == "treat_post") %>% pull(std.error)

# degrés de liberté fondés sur le nombre de clusters (inférence cluster-robuste)
G_2x2       <- n_distinct(main2$cluster_uid)
df_clust    <- G_2x2 - 1
df_resid    <- df.residual(m_main)

mde_emp_from_se <- function(se, df) (qt(1 - alpha/2, df) + qt(power, df)) * se

mde_emp       <- mde_emp_from_se(se, df_clust)
mde_emp_resid <- mde_emp_from_se(se, df_resid)   # ancienne spécification, pour comparaison

11.9 Puissance pour l’hypothèse 2 (impact sur les inégalités)

L’hypothèse 2 (H2) est estimée dans 07-estimation_staggered.qmd avec le même dispositif que H1, mais sur le résultat zscore_wealth : le z-score du centile de richesse standardisé au sein de chaque grappe, \(Z_i = (W_i - \mu_{\text{grappe}})/\sigma_{\text{grappe}}\), conformément au PAP. Cette construction modifie fondamentalement la structure de variance du résultat, et donc la puissance : elle élimine mécaniquement la variance inter-grappes, qui est précisément la source de la faible puissance de H1.

11.9.2 MDE empirique pour H2

11.9.3 Interprétation

  • La MDE pour H2 est d’environ 0,05 z-score (2×2) et 0,03 z-score (échelonné), soit un d de Cohen du même ordre — très inférieur aux MDE de H1 (0,57 et 0,42). La standardisation intra-grappe ramène l’ICC de 0,42 à environ 0, ce qui annule le design effect : la puissance provient de la construction du résultat, non d’un échantillon plus grand.
  • Ordres de grandeur : l’écart-type global observé du z-score est de 0,57 — pratiquement égal à l’écart-type moyen intra-grappe (0,56), conformément à une ICC proche de zéro. Rapportée à cette échelle, la MDE échelonnée (0,028 z) représente 5 % d’un écart-type, environ 4 positions dans le classement interne de richesse du village (déplacement de la médiane au rang 54 sur 100), et environ un quart du seuil de Cohen d’un « petit » effet (d = 0,2) ; la MDE du 2×2 (0,049 z) correspond à ~9 % d’un écart-type, soit ~7 positions. À titre de comparaison, l’intervalle interquartile du z-score (0,37–1,11) vaut environ 26 fois la MDE. La MDE de H2 est donc un seuil bas : les résultats nuls de H2 sont informatifs, contrairement au résultat nul du 2×2 pour H1.
  • Note de construction : le z-score n’est pas centré à zéro dans l’échantillon apparié (médiane 0,72, minimum 0), ce qui indique une standardisation par rapport à une référence plus large (moyenne de l’échantillon DHS complet) plutôt que par rapport à la moyenne de l’échantillon apparié. Cela ne modifie pas la logique de puissance — l’écart-type est l’échelle pertinente — mais explique l’étendue observée (0 à 4,5) au lieu d’un intervalle symétrique autour de zéro.
  • Les estimations H2 (2×2 : −0,02, t ≈ −1,3 ; échelonné : +0,001, t ≈ 0,1) sont donc informatives : l’étude peut écarter des effets supérieurs à ~0,05 z-score sur la position relative des ménages dans leur localité.
  • Mise en garde d’interprétation : un DiD au niveau du ménage sur des z-scores intra-grappes mesure le déplacement de la position relative des ménages traités par rapport à leurs voisins de grappe, et non la dispersion en tant que telle. Un test direct de H2 tel que formulé dans le PAP (« les AP exacerbent les inégalités ») exigerait un résultat de dispersion au niveau de la grappe (p. ex. écart-type ou Gini du centile de richesse par grappe), dont la puissance serait différente (G ≈ 481 observations). Le manuscrit ne doit donc pas présenter la spécification actuelle comme un test direct de la dispersion.
  • En cohérence, la MDE de H1 ne doit pas être convertie en unités de z-score en supposant un même d de Cohen : les deux résultats ont des structures de variance radicalement différentes (ICC 0,42 contre ~0).

11.10 Décomposition de l’écart-type du coefficient DiD

Pour comprendre l’écart entre la MDE de pré-enregistrement (design effect) et la MDE empirique, on décompose la SE en partant de la comparaison de moyennes la plus simple jusqu’à la spécification complète de 07-estimation_staggered.qmd (Abadie et al. 2022).

post21 <- dat %>% filter(DHSYEAR == 2021)

             var(post21[[yvar]][post21$treat == 0], na.rm = TRUE) /
               sum(post21$treat == 0))

11.11 Synthèse et interprétation

  • L’ICC pondérée estimée sur l’échantillon apparié est de 0,42 : plus d’un tiers de la variance de l’indice de richesse se situe entre les grappes, ce qui, avec 25 à 30 ménages par grappe, produit un design effect de 10 à 12.
  • Les MDE sont exprimées en unités de l’indice de richesse utilisé dans l’estimation (wealth_centile_rural_weighted).
  • La MDE empirique (dérivée de la SE des modèles réels, avec \(df = G-1\)) constitue la meilleure estimation de la capacité de l’étude à détecter un effet : elle intègre automatiquement les poids, le matching, les contrôles (SPEI, sexe et âge du chef de ménage), le clustering et la structure DiD. Le choix des degrés de liberté modifie peu les quantiles de t dès que \(G\) dépasse quelques centaines (voir la comparaison df = G − 1 vs df résiduel ci-dessus).
  • L’étude peut détecter des effets d’environ 16 points de centile (d ≈ 0,57) avec le 2×2 et d’environ 12 points de centile (d ≈ 0,42) avec le design échelonné, à 80 % de puissance.
  • L’effet estimé par le design échelonné (+11,6 points de centile, SE = 4,25, t ≈ 2,74, p < 0,01) est à la limite de la MDE empirique (11,9) : il est tout juste détectable, ce qui illustre que l’étude opère à la frontière de sa puissance. Il dépasse en revanche la MDE rapportée dans le PAP (7,45 points), de sorte que l’effet aurait été jugé détectable même selon les critères de la phase de pré-enregistrement — mais uniquement parce que cette MDE était sous-estimée (voir ci-dessus).
  • L’effet du 2×2 (−1,8 point) est non significatif et très inférieur à la MDE (16 points) : ce résultat est non informatif quant aux effets inférieurs à 16 points, et ne doit pas être interprété comme une absence d’effet.
  • Pour H2 (inégalités), le résultat zscore_wealth est standardisé au sein de chaque grappe : l’ICC tombe à ~0 et la MDE empirique n’est plus que de 0,05 z-score (2×2) et 0,03 z-score (échelonné). Les estimations H2 sont informatives (aucun effet détectable sur la position relative des ménages), mais la spécification mesure la position relative intra-grappe et non la dispersion en tant que telle.
  • Le traitement (proximité à moins de 10 km d’une AP) étant attribué au niveau du cluster, la raison « experimental design » de Abadie et al. (2022) s’applique : le clustering des erreurs standards sur hv001/cluster_uid dans 07 est correct.

11.12 Limites

  • La MDE par design effect, telle qu’utilisée à la phase de pré-enregistrement, sous-estime la MDE réelle : elle ne modélise pas la variance d’un coefficient d’interaction DiD, ignore les poids, les tailles de grappes inégales et le déséquilibre entre bras. Les bornes issues de cette approche doivent être lues comme optimistes ; la MDE empirique fait référence.
  • L’ICC pondérée via lmer(weights=) traite les poids comme des poids de fréquence (réplication) ; c’est acceptable pour une estimation de variance, mais l’ICC exacte dépendrait de la méthode d’estimation pondérée retenue.
  • Le calcul suppose une répartition de l’effet homogène dans le temps post-traitement.
  • La MDE empirique est conditionnelle à la spécification estimée (contrôles, poids, structure de clustering) ; toute modification de la spécification de 07 modifierait la MDE.
  • La correction des dates de création des AP a réduit l’échantillon de traitement (ménages appariés de 15 328 à 13 444 ; clusters de 566 à 481) ; les MDE rapportées ici reflètent l’échantillon corrigé.
